# 📚 Console Library System

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)  
![Language](https://img.shields.io/badge/C%23-8.0-blueviolet)  
![Platform](https://img.shields.io/badge/.NET-8.0-green)  

A simple **C# console application** for library management.  
It allows you to register books and users, process loans, add reviews and ratings, and view both general and detailed statistics.

## ⚙️ Installation

- Clone the repo
- Open in your preferred C# IDE and run Program.cs

## 🛠️ Prerequisites

- .NET SDK 8.0+
- C# IDE (Visual Studio, Rider, VS Code, etc.)

## 📂 Project Structure

The project consists of a single Program.cs file, which covers:

- 📕 Book management
- 👤 User management
- 📖 Loans
- ⭐ Reviews & ratings
- 📊 General & detailed statistics
